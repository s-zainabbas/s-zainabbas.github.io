A single page that shows my work and also is my work. Every line is hand-written HTML, CSS and JavaScript, with no template and no framework. It has a WebGL hero, animations that follow the scrollbar, live project previews and a full French version, and it costs nothing to host.

The brief

A CV says what I've done. I wanted a site that proves it: somewhere a recruiter or a client can see my experience in a minute, then try the things I've built without leaving the page.

I set myself three rules. No templates, so every part is something I can explain. No server, so it stays free and fast. And it has to feel alive (motion, depth, interactive previews) while still being quick on a phone and readable for everyone.

How it fits together

The whole site is static files. One HTML page holds the ten sections. Three plain JavaScript files, each with one job, add the behaviour. A few trusted libraries load from CDNs, and the only outside service is the one that delivers contact-form messages to my inbox.

What happens when the page opens

First impressions are mostly about the first second. The page is ordered so that something correct appears straight away, and the heavy parts wait until they're needed.

Scroll, frame by frame

Sections don't just fade in once. Their 3D tilt, depth and opacity are tied to the scrollbar, so scrolling back up plays them in reverse. That means 43 elements recalculated on every frame, and the first version stuttered.

The cause was a classic one: each frame read the position of every element right after writing new transforms, which forces the browser to redo the page layout before it can answer. The fix was to measure positions only when the layout actually changes, then do nothing but arithmetic while scrolling.

Two languages, one page

I work in Geneva, so French isn't optional. Rather than keep two copies of the site in sync, the page is written once in English and i18n.js swaps the words in place. Press the FR button, or L anywhere on the page.

Decisions worth explaining

No framework on purpose

The page is content first, so plain JavaScript keeps it light and every interaction stays mine to explain. Tailwind is only used at build time and compiles down to an 11 KB stylesheet.

Live previews, not screenshots

Game of Life runs on typed arrays and pauses off screen. The moving-average chart uses a seeded random walk, so “new chart” gives fresh but repeatable data.

A keyboard way around

Press ⌘K (or Ctrl+K) for a command menu that jumps to any section, opens a case study, copies my email or downloads my CV. T switches the theme.

Logos that fit the band

Partner logos become soft white silhouettes on the grey band. Where a logo had dark lettering inside a shape, like FUNdamental's “FUN”, I cut the letters out so they still read.

Private by default

No cookies and no tracking scripts. Theme and language are saved in the browser, and visitor stats, when switched on, use GoatCounter, which stores no personal data.

Readable for everyone

A skip link, labelled controls, real headings and alt text. Decorative motion like the footer stamp stops when a visitor asks for reduced motion.

Six years of one site

The site has been rebuilt more than once, but it's always been hand-coded. Each version reflects what I could do at the time.

Trade-offs

  • The animated background and 3D hero are the site's signature, so they stay on for everyone. To keep them cheap, the particles draw at standard resolution and the hero only renders while visible.
  • Translating by swapping text means a new English sentence needs a matching French entry, or it stays in English.
  • Without a server, the contact form relies on FormSubmit to deliver messages. In return there's nothing to host, patch or pay for.
  • The case-study pages are English only for now.
