Stockify.

A fast stock tracker I use every day. One page with my own setup ready on load: 20, 50 and 200-day EMAs, the key numbers, a technical rating and the latest news. It costs nothing to run.

Role
Design, development, deployment
Stack
JavaScript modules, TradingView widgets
Hosting
GitHub Pages, deployed by GitHub Actions
Running cost
$0: no server, no API key
Open Stockify Source code

The problem

I check the same few stocks every day. What I wanted on screen was always the same: a daily chart with the 20, 50 and 200-day exponential moving averages, the price and valuation numbers, a quick technical read and the news. Getting there meant setting it up again on every visit.

So I built one page that opens with all of it already in place, loads fast, and works on my phone as well as my laptop.

From an API to no backend at all

The first version pulled prices from the Twelve Data API. That meant an API key to keep secret, request limits to stay under, and my own code to turn raw prices into indicators.

The current version embeds TradingView's free widgets instead. Each widget loads its own market data in the visitor's browser, so Stockify has no server, no API key and no scheduled data job. My code focuses on what I care about: the setup, the search, the watchlist and how it all fits together.

How it fits together

The app is a handful of plain JavaScript modules with no dependencies. One search box drives five widgets, so choosing a ticker updates the whole page at once.

Decisions worth explaining

Three EMAs in one study

The free chart widget can't colour separate EMA studies differently. I used TradingView's Moving Average Ribbon and set its lines to EMA 20, 50 and 200, so each line still gets its own colour.

Search that never says no

Popular tickers are suggested as you type, and anything else opens on Enter, including exchange prefixes like NYSE:KO. Press / from anywhere to jump to search.

Links you can share

?symbol=MSFT opens a stock directly, so a chart can be sent to someone or bookmarked.

Private by default

The watchlist and theme live in the browser through a small storage module. There's no account and nothing to sign up for.

Trade-offs

  • Prices come from TradingView and may be delayed, depending on the exchange.
  • Clicking inside a widget, such as a ticker in the top strip, opens TradingView in a new tab. That's how the free widgets behave.
  • Removing the backend meant giving up my own indicator code. In return there's no key to leak, no rate limit and nothing to maintain on a server.
  • Stockify is for information only and is not financial advice.
